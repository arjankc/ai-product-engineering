# Exam rubric — CS101

## Midterm (25% of course grade)

| Section | Points | What graders look for |
|---------|--------|------------------------|
| Big-O short answers | 30 | Worst-case stated; tight bound preferred |
| Trace a recursive function | 30 | Correct base case + stack trace |
| Short code write | 40 | Readable JS; handles empty input |

## Final (25% of course grade)

Cumulative. Expect one question that combines sorting analysis (Assignment 2) with recursion.

## Partial credit

- Showing the recurrence even if the closed form is wrong: up to half credit on that item.
- Blank answers: zero — write something structured.
