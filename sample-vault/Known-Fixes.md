# Known Fixes

## Printer appears offline

1. Confirm the computer can reach `192.168.1.1`.
2. Check the printer network light and cable.
3. Ping `192.168.1.50`.
4. If ping works, remove paused jobs and restart the print spooler.
5. If ping fails but link is lit, confirm the reserved IP on the router.

Record changes before replacing cables or ports.
