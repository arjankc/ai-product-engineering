# Network Topology

## Address plan

- Gateway/router: `192.168.1.1`
- Office printer: `192.168.1.50`
- DHCP clients: `192.168.1.100`–`192.168.1.199`
- Wi-Fi SSID: `Workshop-5G`; guest devices use `Workshop-Guest`.

The printer uses a reserved address and should not be switched to DHCP. Test the gateway before blaming an endpoint.
